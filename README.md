# SkyNetwork Voice

Сервер голосовой радиосвязи сети виртуальной авиации **SkyNetwork**, написан на C++17. Работает по UDP, порт `3782`.

Сервер **не декодирует звук**. Клиент сообщает свои трансиверы (частота, координаты, высота антенны) и отправляет кадры **Opus** с отметкой, на каких трансиверах идёт передача. Сервер пересылает кадр только тем, у кого есть трансивер на той же частоте в пределах прямой видимости УКВ: `1.23·(√h1 + √h2)` nm. К кадру он добавляет **силу сигнала** от 0 до 1. По ней голосовой клиент накладывает затухание, шум и полосовой фильтр УКВ-радио.

Формат пакетов описан в `src/voice_server.h`. Аккаунты хранятся в той же базе SQLite, что и у FSD-сервера сети (репозиторий **Skynetwork-fsd**).

Раз в 10 секунд (`--account-check`) сервер сверяет подключённых с базой. Заблокированного на сайте он отключает пакетом `KICK` с причиной `CID suspended` и больше не пускает.

## Клиентская библиотека

`client/SkyNetwork.Voice` — голосовая часть клиентов SkyPilot и Network-ATC (.NET 8). Каждый из них держит у себя копию этой папки.

- `VoiceConnection` — вход по CID и паролю, трансиверы, аудио, keepalive, отключение сервером.
- Кодек Opus (Concentus, чистый C#, без нативных библиотек): 48 кГц, моно, кадры по 20 мс, 24 кбит/с, FEC.
- `RadioMixer` — по потоку на каждую передающую станцию:
  - джиттер-буфер 60 мс, маскировка потерь, переупорядочивание;
  - эффект УКВ-приёмника: полоса 300–3000 Гц, лёгкая компрессия, шум, растущий по мере ослабления сигнала;
  - «хвост» шумоподавителя в конце передачи.
- `Transmitter` — микрофон в эфир, пока нажата кнопка передачи. При отпускании уходит закрывающий кадр, и у слушателей шумоподавитель закрывается сразу.
- `PushToTalk` — клавиша, кнопка мыши или кнопка джойстика. Работает, даже когда в фокусе симулятор.
- `VoiceClient` — всё вместе: радиостанции (частота, приём, передача, громкость), антенны (самолёт или точки диспетчера), устройства Windows (NAudio).
  - Радиостанция не принимает, пока на ней идёт передача.
  - Серверу уходит до 8 трансиверов.

```bash
dotnet test client/SkyNetwork.Voice.sln   # после cmake --build build: тесты используют настоящий сервер
```

## Сборка и запуск

```bash
sudo apt install cmake g++ libssl-dev libsqlite3-dev
cmake -B build && cmake --build build -j
./build/skynet-voice --db skynetwork.db --port 3782
```

Порт — **3782/UDP**. На сервере сети голос ставится рядом с FSD-сервером и сайтом: служба `skynet-voice` описана в `deploy/` репозитория Skynetwork-site, скрипт `deploy/update.sh` собирает и перезапускает её вместе с остальными.

```bash
sudo ufw allow 3782/udp
```
